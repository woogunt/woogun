# 내 말투 자소서 ✍️

내 경험과 지원 회사·직무·문항을 넣으면, **내가 쓴 것 같은 말투로** 자기소개서를 써주는 앱입니다. (Claude API 사용)

## 동작 방식

1. **① 내 말투 학습** — 예전에 쓴 자소서·블로그·리포트를 붙여넣으면 AI가 종결어미, 문장 길이, 자주 쓰는 표현, 전개 방식 등을 분석해 *문체 프로필*을 만듭니다. 프로필은 직접 고칠 수 있어요.
2. **② 경험 뱅크** — 경험을 STAR(상황·행동·결과) 형태로 저장합니다. AI는 **여기 적힌 사실만** 사용하고 수치나 성과를 지어내지 않습니다.
3. **③ 자소서 작성** — 회사, 직무, 채용공고/인재상, 문항과 글자수를 넣으면
   - 문항 의도 분석 → 사용할 경험 선택 → 구성 계획을 먼저 세우고
   - 문체 프로필대로 본문을 쓴 뒤
   - 글자수(공백 포함)를 넘으면 자동으로 줄입니다.
4. **④ 작성 기록** — 결과를 직접 고치거나 "두 번째 문단 더 구체적으로" 같은 수정 요청으로 다시 쓰게 할 수 있습니다.

데이터는 `jasoseo/data/db.json` 에 내 컴퓨터에만 저장됩니다 (git에는 올라가지 않음).

## 실행

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # 또는 앱 사이드바에 직접 입력
streamlit run app.py
```

API 키는 https://console.anthropic.com 에서 발급받을 수 있습니다.

## 팁

- 말투 샘플은 **3개 이상, 총 2,000자 이상**일 때 결과가 확실히 좋아집니다. 자소서뿐 아니라 평소 쓴 글도 섞어 넣어보세요.
- 경험의 *결과*에는 숫자를 최대한 적어주세요. (예: "참여율 40% → 65%")
- 사이드바의 *작성 품질(effort)* 을 올리면 더 공들여 쓰지만 느려지고 비용이 늘어납니다.

## 웹 버전 (claude.ai 아티팩트)

`web/jasoseo.html` 은 claude.ai 에 비공개 페이지로 게시되어 있습니다. API 키나 서버 없이 폰 브라우저에서도 동작합니다.

1. 공고(텍스트 또는 사진)와 문항을 붙여넣고 **문항 나누기**
2. **사실 확인하기**: 문항마다 STAR(상황·과제·행동·결과) 칸에 경험 뱅크에서 찾은 사실을 채우고, 빈칸은 질문합니다
3. 질문에 답하면(모르면 "모름") 다시 확인하고, 빈칸이 없는 문항만 STAR 순서로 씁니다

데이터는 페이지 저장소에 보관되며 만든 사람만 읽고 쓸 수 있습니다.
