# 우리둘 💕

커플을 위한 모바일 웹앱. 설치나 서버 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있습니다.

## 기능
- **홈 대시보드**: D+day, 다음 기념일까지 남은 날, 함께한 주/시간, 오늘의 기분(둘 다), 다가오는 일정, 기념일 목록, 최근 편지
- **캘린더**: 월별 달력, 날짜별 일정 추가/삭제, 기념일 자동 표시
- **버킷리스트**: 함께 하고 싶은 일 체크리스트 + 진행률
- **편지**: 서로에게 짧은 편지 남기기
- **앨범**: 사진 업로드(자동 리사이즈), 크게 보기/삭제
- **설정**: 이름·처음 만난 날 수정, 만난 날을 1일로 세기, 데이터 내보내기/가져오기/초기화, 다크 모드

## 참고
- 데이터는 현재 브라우저의 `localStorage`에만 저장됩니다. 두 사람이 실시간으로 공유하려면 백엔드(예: Firebase/Supabase)가 필요합니다.
