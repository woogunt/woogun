앱 아이콘

아이콘을 바꾼 뒤에는 홈 화면의 앱을 지우고 Safari에서 다시 ‘홈 화면에 추가’해야 새 아이콘이 보여요. 아이폰은 추가할 때의 아이콘을 저장해 두기 때문이에요. 맥은 Dock에서 지우고 ‘파일 → Dock에 추가’를 다시 하면 돼요. 입력한 월급과 비율은 그대로 남아요.

기기 연동 (아이폰 ↔ 맥 ↔ Safari)
월급·비율·실제 금액·아이콘을 내 GitHub 비공개 저장소에 저장해서, 어느 기기에서 열어도 같은 내용이 나와요. 기기(또는 홈 화면 앱)마다 처음 한 번만 연동하면 돼요.
  1. GitHub에 비공개(Private) 저장소 salary-data 만들기
  2. 토큰 만들기: Settings → Developer settings → Fine-grained tokens → 이 저장소만 선택, Contents: Read and write
  3. 아래에 저장소 이름과 토큰을 넣고 연동하기
