# 시뮬레이션·신호 스크립트

| 파일 | 하는 일 |
|---|---|
| `fetch.py` | Yahoo Finance에서 10년치 일별 수정주가를 받아 `data/prices.csv`에 저장 |
| `signals.py` | 시장판(지수·환율·금리·원자재), 지수 추세(200일선), 개별 종목 모멘텀 순위와 매수 후보를 `signals.json`에 저장 |
| `build_page.py` | `signals.json`을 `../ai-office.html`에 넣음 |
| `intramonth.py` | 월중 매수·매도 규칙 비교 (일 단위) |
| `backtest.py` | 개별 종목 선정 규칙 (매달 50만원)
- ISA 30만원, 지수 ETF만: TIGER 미국나스닥100 10만, TIGER 미국S&P500 10만, KODEX 200 7만, KODEX 코스닥150 3만. 팔지 않고 계속 적립.
- 일반 계좌 20만원, 개별 종목만: 12개월(최근 1개월 제외) 상승률 상위이면서 200일 평균선 위인 5개를 4만원씩.
- 매달 첫 거래일에 후보를 다시 고르고, 후보에서 빠진 종목은 팔아서 새 후보에 넣는다.
  (15위 밖으로 밀릴 때까지 들고 가는 규칙도 백테스트했지만 매달 다시 고르는 쪽이 나았다: `backtest.py`)
- 월중(매일 3번 점검): 보유 종목이 순위 20위 밖으로 밀리면 매도 신호, 그 빈자리에 조건을 맞는 다음 종목을 매수 신호.
  200일선 아래 마감이나 매수 후 고점 대비 -15%는 '주의'만 보낸다. 이런 때 바로 파는 규칙들은 백테스트에서 수익을 크게 깎았다: `intramonth.py`
- ISA 지수 ETF도 200일선 아래에서 팔면 하락 폭은 줄지만 4개 모두 수익이 낮아져서 계속 보유한다.

투자 권유가 아니며, 과거 성과와 시뮬레이션은 미래 수익을 보장하지 않는다.
